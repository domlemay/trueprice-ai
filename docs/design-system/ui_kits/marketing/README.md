# Marketing UI Kit

Public-facing landing for **truepricai.ca**.

## Sections (in order)
1. **Navbar** — sticky, navy backdrop blur, brand logo + AI badge, primary nav, login + "Essayer gratuitement" CTAs
2. **Hero** — split: tagline / search / trust pills (left) · glassmorphic mock with price comparison (right) + floating exchange-rate + savings cards
3. **Comment ça marche** — 3 numbered step cards
4. **Tarifs** — 3 plans (FREE / PREMIUM / ENTREPRISE), middle card featured with glow + "Le plus populaire" pill
5. **CTA final** — cyan-tinted halo card
6. **Footer** — 4-column

## Components used
`btn` (primary / secondary / lg) · `pill` (trust badges) · `card-featured` · `plan-card` · `step-card` · `price-row-marketing` · `breakdown-mini` · `float-card`

## Source
Patterns lifted from `domlemay/trueprice-ai`: `components/landing/{Hero,Navbar,Pricing,Features}.tsx`. Color palette **remapped** to cyan/navy per the v1.0 brief.
